\section{Reproducibility and provenance}

The repository separates source acquisition, ingestion, deterministic
projection, statistical modeling, and presentation. Download manifests record
source URLs, versions, sizes, and SHA-256 fingerprints. Unmatched location codes
stop a build. Generated model outputs remain distinct from reference targets
used for validation.

The final artifact build will create every paper and webpage figure from the
same result tables. The paper will record its version, Git revision, WPP data
vintage, projection vintage, source fingerprints, software environment, and
generation date. A reviewed PDF will be stored at a stable path, while released
versions remain immutable.

The first real UW fixture used R 4.4.2, \texttt{bayesTFR} 7.4-4, and the exact
UW Git revision of \texttt{bayesLife} 5.3-0 used to create the archive. Official
accessors exported Finland's 1,000 trajectories for 2023--2100 and applied 78
stored alignment-shift values to each component. The extracted code set
confirmed 236 locations and identified Holy See (M49 336) as the sole WPP 2024
omission. Archive, reader-source, and export-file SHA-256 fingerprints are
recorded in the repository manifests.

The schedule-conversion appendix will report reconstruction tolerances and the
fertility-mortality pairing rule. The mechanism appendix will provide the
complete parameter-provenance table, prior predictive checks, sampler
diagnostics, retrospective tests, and sensitivity analyses.
